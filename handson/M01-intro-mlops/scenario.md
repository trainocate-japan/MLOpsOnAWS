# モジュール 1: MLOps の導入 - ハンズオンシナリオ

## シナリオ概要

あなたは AnyCompany Consulting の MLOps エンジニアとして着任しました。
データサイエンスチームは優れた ML モデルを作りますが、本番環境への移行に何週間もかかり、
デプロイのたびに手作業が発生しています。あなたの最初の仕事は、**現状の課題を MLOps の観点で整理し、
チームがどの成熟度レベル（Initial → Repeatable → Reliable → Scalable）にいるかを把握する**ことです。

このモジュールでは AWS リソースは作成しません。MLOps の全体像・ML ライフサイクル・DevOps との違い・
成熟度モデルを、Python スクリプトで整理しながら理解します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **MLOps を定義する**: 人・プロセス・テクノロジーの組み合わせとして MLOps を説明できる
2. **ML ライフサイクルを説明する**: ビジネス課題からモデル評価・デプロイ・監視までの反復プロセスを理解する
3. **DevOps と MLOps を比較する**: コードに加えてデータとモデルを扱う点の違いを説明できる
4. **成熟度モデルを説明する**: Initial / Repeatable / Reliable / Scalable の各段階の特徴を挙げられる
5. **ML ガバナンスを定義する**: 透明性・説明可能性・監査可能性・セキュリティの必要性を理解する

## MLOps の 3 本柱（スライド対応）

| 柱 | 内容 |
|----|------|
| プロセス (Process) | ML ライフサイクルと、それが MLOps とどう関連するか |
| ピープル (People) | DevOps / データ / データサイエンス / MLOps / ガバナンスの各ロールの連携 |
| テクノロジー (Technology) | トレーニング・デプロイパイプライン、リポジトリ、モニタリング |

さらに **セキュリティとガバナンス**（MLSecOps・ML ガバナンス）が全体を支えます。

## MLOps 成熟度モデル（スライド対応）

| レベル | コラボレーション | データ処理 | トレーニング | デプロイ |
|--------|----------------|-----------|------------|---------|
| Initial | 分断されたチーム | 1 回限りの収集・準備 | 手動 | 手動・一貫性なし |
| Repeatable | 目標の共有 | 自動データパイプライン | 自動ビルドパイプライン | 手動検証 |
| Reliable | 部門横断チーム | データガバナンス | 自動検証・CI/CD | 自動化された CI |
| Scalable | 全社的なベストプラクティス共有 | セルフサービス | 完全自動化 | ダッシュボードと透明性 |
