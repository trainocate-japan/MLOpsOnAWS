# モジュール 2: Initial MLOps - SageMaker Studio の実験環境 - ハンズオンシナリオ

## シナリオ概要

AnyCompany Consulting は水産養殖の顧客から「**アワビ (Abalone) の年齢を、殺さずに物理的な測定値から予測したい**」
という相談を受けました。アワビの年齢は通常、殻を切って輪紋 (rings) を数える必要があり、手間がかかります。
そこで、性別・長さ・直径・重量などの測定値から輪紋の数（＝年齢の指標）を予測する回帰モデルを構築します。

あなたは MLOps エンジニアとして、データサイエンティストが Amazon SageMaker AI で
**再現性のある標準化された実験環境**を使ってモデルを学習できるようにします。
このモジュールでは、組み込みアルゴリズムとスクリプトモード (BYOS) の 2 つの方法でモデルを学習します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **実験データを準備する**: アワビデータを取得・前処理し、S3 に train/validation として配置する
2. **組み込みアルゴリズムで学習する**: SageMaker の組み込み XGBoost でトレーニングジョブを実行する
3. **コンテナの仕組みを理解する**: SageMaker がトレーニング用に Docker コンテナを起動することを確認する
4. **BYOS を使う**: スクリプトモードで独自のトレーニングスクリプトを持ち込む
5. **モデルアーティファクトを確認する**: `model.tar.gz` が S3 に出力されることを確認する
6. **実験環境を理解する**: SageMaker Domain・ユーザープロファイル・ライフサイクル構成の役割を説明する

## コンテナアプローチの選択（スライド対応）

| アプローチ | 内容 | ユースケース |
|-----------|------|------------|
| 組み込みアルゴリズム | AWS 提供のアルゴリズムをそのまま使う | 標準的な問題（本モジュールの XGBoost） |
| BYOS（独自スクリプト） | AWS 管理コンテナ + 自分の学習スクリプト | フレームワークは標準だがロジックは独自 |
| BYOC（独自コンテナ） | 自分でビルドしたコンテナを ECR に登録 | 独自フレームワーク・特殊な依存関係 |
| BYOM（独自モデル） | ローカル等で学習済みのモデルを持ち込む | 既存モデルの活用 |

## 使用する AWS サービス

- Amazon SageMaker AI（トレーニングジョブ、Estimator）
- Amazon S3（データ・モデルアーティファクトの保管）
- Amazon ECR（組み込みアルゴリズムのコンテナイメージ）
