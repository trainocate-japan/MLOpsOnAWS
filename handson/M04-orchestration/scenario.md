# モジュール 4: Repeatable MLOps - オーケストレーション - ハンズオンシナリオ

## シナリオ概要

AnyCompany Consulting のアワビモデルは、データ準備・学習・評価・登録を毎回手作業でつないでいます。
あなたは MLOps エンジニアとして、これらを **1 つの再現可能なパイプライン**にまとめ、
「メトリクスのしきい値を満たしたモデルだけを Model Registry に登録する」自動化を実装します。

さらに、学習したモデルをリアルタイム推論エンドポイントとしてデプロイし、
ユースケースに応じた推論オプション（リアルタイム / サーバーレス / 非同期 / バッチ）を比較します。

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **ML パイプラインを自動化する**: SageMaker Pipelines で処理→学習→評価→条件→登録をつなぐ
2. **条件ステップを使う**: 評価メトリクスがしきい値を満たす場合のみ登録する
3. **パイプラインパラメータを使う**: インスタンスタイプなどを実行時に変更できる（反復可能性）
4. **リアルタイムエンドポイントをデプロイする**: モデルをホストして推論を実行する
5. **推論オプションを比較する**: リアルタイム / サーバーレス / 非同期 / バッチ変換の使い分け

## モデル構築パイプラインのステップ（スライド対応）

```
データ処理 → モデルトレーニング → モデル評価 → [条件: RMSE がしきい値以下?] → モデル登録
```

## 推論オプションのビジネスケース（スライド対応）

| オプション | 向いているケース |
|-----------|----------------|
| リアルタイム | 低レイテンシーの同期推論（常時稼働） |
| サーバーレス | 断続的なトラフィック・コールドスタート許容 |
| 非同期 | 処理時間が長い・大きなペイロード・キューイングが有効 |
| バッチ変換 | 大規模データセット全体のオフライン推論 |

## 使用する AWS サービス

- Amazon SageMaker Pipelines（ProcessingStep / TrainingStep / ConditionStep / RegisterModel）
- Amazon SageMaker AI（リアルタイムエンドポイント）
- AWS Step Functions（エンドツーエンドオーケストレーションの選択肢として紹介）
