# モジュール 5: Reliable MLOps - スケーリングとテスト - ハンズオンシナリオ

## シナリオ概要

AnyCompany Consulting のアワビ予測 API は好評で、トラフィックが増減するようになりました。
また、データサイエンスチームは精度を改善した**新しいモデル**を作り、本番の現行モデルと比較したいと考えています。

あなたは MLOps エンジニアとして、Reliable フェーズに進むために次を実装します。
- 負荷に応じてエンドポイントを自動スケールする**オートスケーリング**
- 現行モデルと新モデルを安全に比較する **A/B テスト**と**シャドーテスト**
- リスクを抑えてモデルを切り替える**ブルー/グリーンデプロイ**（Canary / Linear）

## 学習目標

このハンズオンを完了すると、以下ができるようになります。

1. **オートスケーリングを設定する**: ターゲット追跡ポリシーでエンドポイントをスケールする
2. **A/B テストを実装する**: 複数の本番バリアントに加重ルーティングする
3. **シャドーテストを実装する**: 本番トラフィックを複製して新モデルを評価する（応答は返さない）
4. **ブルー/グリーンを説明する**: All-at-once / Canary / Linear のトラフィックシフトを比較する
5. **マルチアカウント戦略を説明する**: 環境分離とアクセス制限のベストプラクティス

## テスト戦略の比較（スライド対応）

| 戦略 | 内容 | 特徴 |
|------|------|------|
| A/B テスト | 複数バリアントに実トラフィックを加重配分 | 両モデルの実応答を比較できる |
| シャドーテスト | 本番トラフィックを複製して新モデルに送る | 新モデルの応答は返さない（ユーザー影響なし） |

## ブルー/グリーンのトラフィックシフト（スライド対応）

| パターン | 内容 |
|---------|------|
| All at once | すべてのトラフィックを一度に新環境へ |
| Canary | 一部を先行させ、ベイク期間後に残りをシフト |
| Linear | 一定割合ずつ、等間隔で段階的にシフト |

## 使用する AWS サービス

- Amazon SageMaker AI（マルチバリアントエンドポイント、シャドーバリアント）
- Application Auto Scaling（ターゲット追跡スケーリング）
- Amazon CloudWatch（スケーリングメトリクス）
